# Testing & Documentation

This folder/documentation set supports the Testing & Documentation Lead role for the Weather & Disaster Early-Warning Board project.

## Documents
- `Test-Cases.md` – planned functional test scenarios.
- `Testing-Checklist.md` – checklist for manual UI checks.
- `Test-Execution-Report.md` – record actual test outcomes after execution.
- `Bug-Report-Template.md` – standard format for reporting defects.

## Testing Approach
1. Open the application in the browser.
2. Check each feature against its expected behavior.
3. Record the actual result and status.
4. Capture evidence for failures where possible.
5. Report issues using the bug-report template.
6. Retest fixes and update the execution report.

## Important
The project currently uses a prototype/demo experience. Do not describe simulated or static information as live weather data unless a live data source has been integrated and verified.
